# Amazon Keyword Filter

筛选用户提供的亚马逊关键词研究文件，输出可追溯、按优先级排序的 Listing 和广告关键词。用户默认只提供第2、3、4、5类文件，不需要单独提供产品资料。第1类竞品反查文件中的关键词及上下文默认作为目标产品主题的依据；如用户在本批文件中说明产品与该主题不同，以用户说明为准。

## 输入识别

默认识别以下来源类别，文件可能是 Excel、CSV 或 TSV，列名和语言可能不同：

1. **竞品页面反查词**：来自相同或相似度达到90以上的竞品页面。
2. **搜索结果竞品统一流量词**：用户以第1类中的相关高流量搜索词查询亚马逊后，对搜索结果竞品统一挖掘所得。
3. **广泛流量词**：流量大但范围较宽的词。
4. **亚马逊下拉词/相关搜索词**：平台推荐表达；没有搜索量数据时只视为意图线索，不视为流量证明。

依据文件名、表头、字段值和用户描述判断类别，不能仅凭文件顺序猜测。允许字段映射不确定；先展示识别到的类别、关键字段和明显缺口，再继续可完成的分析。若第1类文件缺失且其它文件无法可靠界定产品主题，明确提示相关性判断受限；不得将明显低相关词因流量高而判为优质。

提取并保留可用字段，例如关键词、搜索量、ABA排名、相关度、竞品/ASIN、自然排名、点击或转化份额、竞品覆盖数、供需比、PPC竞价、来源查询词、平台出现位置和采集日期。先按列名、数据样例和工作表结构识别字段语义，不按列位置盲猜。常见 SellerSprite 导出中，各类表结构可能不同：

- 竞品反查表可能包含“预计月搜索量”、点击占比、关键词类型、自然/广告排名、ABA排名和竞品信息；点击占比不是相关度，ABA排名不是搜索量。
- 搜索词/广泛流量词表可能包含数值型相关度（如0–100）、ABA当期/前期排名、搜索量、SPR、商品数、供需比及点击/转化份额。不得把ABA排名误认为搜索量，也不得把商品数直接等同于竞品难度。
- 识别或映射存在歧义时，保留原始列名和原值，说明无法确认的字段；不得据列序猜测或制造统一指标。

对不可比字段分别标准化；绝不把缺失值当作零、低竞争或高置信度。尤其不能把一类的预计月搜索量与二/三类搜索量直接当作同一口径。只有定义和单位确认一致后才可横向比较。

## 筛选与排序

- 先将关键词和指标对齐，保留原始值；合并大小写、空格、单复数、连字符等明显等价项。语义接近但意图不同的完整词组不要误合并。去重后保留全部来源、出现次数和证据。
- 明显与产品类型、功能、适用对象、规格/材质/尺寸冲突的词硬性淘汰，并记录原因。对边界词标为待复核，不自行编造产品事实。
- 默认决策优先级为产品相关性，其次流量，再参考竞争因素。60/25/15仅作为候选的方向性权重，不能在输入字段语义、尺度或数据来源不可比时宣称计算了精确加权总分。相关度数字只有在确认定义和尺度一致时才用于评分；竞品反查表里的点击占比、点击份额、词类型或排名不得冒充相关度。
- 竞争数据在综合总榜中展示但**不计入总分**；在分层清单中用于同等相关和流量词的排序微调，高竞争信号词靠后。区分“商品数”“竞品数”“供需比”和PPC竞价，不能把它们混称竞争度。字段含义无法确认时只展示原值并标为口径待确认。
- 当跨文件指标不可比时，使用明确的定性排序：硬性相关性筛除、产品词义匹配、来源交叉验证、各自文件内相关度/流量排序、竞争信号辅助。说明综合榜依据，不输出伪精确总分。数据不足时按可用证据降级并标注置信度。
- **第1类**侧重产品相关性、多个相似竞品重复覆盖、购买意图及可用流量指标。
- **第2类**侧重亚马逊搜索路径相关性、多个搜索结果竞品的共同覆盖、长尾购买意图和流量证据。
- **第3类**虽可流量大，但需通过基本相关性门槛；作为拓展入口，不能仅凭流量压过高度相关词。
- **第4类**按平台意图信号单独评价：相关性优先，其次是出现在搜索下拉还是结果页相关搜索、跨种子词/路径重复、购买意图、与其它来源交叉验证。单次出现只作为候选。明确标注“平台推荐不代表搜索量”。只有平台推荐证据的词进入平台候选分层，不得伪称有流量数据或与有流量数据的词作伪精确分数比较。
- 下拉/相关搜索词如果也出现在第1至第3类，合并来源后按常规总榜评估；只有推荐信号的词不占用总榜固定配额，可在“待验证候选”列出。

## 结果格式

同时提供两种结果：

1. **分层清单**：按第1、2、3类分别排序，每类默认最多10个；不足10个合格词时如实少列。第4类另列平台意图候选，不硬塞入前三类。
2. **综合总榜**：默认输出25个词，按相关性优先并结合流量证据、来源交叉验证和类别梯度排序；默认类别结构目标为第1类40%、第2类40%、第3类20%。这是目标配比而非填满要求：某类质量不足时由其它合格类别补位，不为凑比例纳入低质量词。若达到质量门槛的词不足25个，则如实少列并说明原因，不得用低相关词凑数。只有平台推荐证据的词单独列待验证，不进入有流量依据的总榜。

总榜默认目标为25个词；只输出达到质量门槛的词，合格词不足25个时不强行凑数并说明原因。结果需要清晰到可直接复制；使用完整关键词，不拆词根。

每个入选词尽量报告：排名、关键词、来源类别/文件、相关性证据、可用流量指标及原值、字段口径、竞争数据及原值、评分或等级、Listing适配建议、广告测试建议、入选理由、缺失字段/置信度。区分文件实测字段、来源频次和分析判断。若表格之间指标不同口径，在表头或说明中明确指出，并禁止直接作数值高低比较。Listing建议可定位标题/五点/描述/后台词，但不要声称索引或排名保证。广告建议用于优先级与测试，不代替投放结果数据。

同时给出：

- 淘汰或待复核词及简明原因，优先列明显冲突和误导性大流量词。
- 字段映射和数据缺口摘要；只在缺口实质影响结论时说明。
- 平台推荐词声明：没有搜索量/点击/转化数据时，不能把推荐出现等同于流量大小。

保持简洁并突出可执行顺序。每次完成关键词筛选后，默认同时在对话中汇报摘要，并生成一份 `.xlsx` 结果工作簿放到用户桌面；这是该 Skill 的默认交付，不需要用户每次重复要求。文件名使用可识别的产品主题和筛选日期/时间，例如 `产品主题_关键词筛选_YYYYMMDD_HHMM.xlsx`；清理文件名中的非法字符，若同名文件已存在则追加序号，不覆盖旧结果。若桌面不可写，保存到当前可用工作目录并在回复中说明实际路径。

工作簿按实际输入和结果设置清晰、可筛选的表格，默认包含：

1. **综合总榜**：最终推荐顺序、完整关键词、类别、来源、相关性/流量证据、字段口径、竞争信息、Listing与广告建议、入选依据和数据缺口。
2. **分层清单**：第1、2、3类分别排序，每类默认最多10个；用类别字段区分，不足则少列。
3. **平台候选**：第4类下拉/相关搜索词，标出种子词、出现位置、重复/交叉验证情况和“无流量数据”状态。没有第4类输入时保留简短说明或省略空表。
4. **淘汰与复核**：淘汰词或边界候选、来源及原因；没有此类词时可注明无。
5. **字段口径**：仅当多来源字段定义、单位或映射需要解释时保留必要说明，避免重复堆叠文档。

工作簿应保留可追溯的原始来源名称和关键原值，不把分析判断伪装成原始数据；仅“综合总榜”默认删除“来源文件”列，其他面向用户的工作表（如分层清单、淘汰与复核）保留来源文件信息。综合总榜仍可保留“来源类别”、出现次数、跨来源交叉验证等汇总证据。按用途设置冻结表头、筛选和易读列宽。只有用户明确要求其他文件格式时才替换 `.xlsx` 默认格式；在对话中提供工作簿链接和简短结果摘要。
