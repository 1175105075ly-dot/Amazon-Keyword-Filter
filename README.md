# Amazon Keyword Filter

筛选亚马逊关键词研究文件，去重并按产品相关性、流量证据、来源交叉验证和竞争信号排序。支持竞品页面反查词、搜索结果竞品流量词、广泛流量词及亚马逊下拉/相关搜索词，并生成便于复核的 Excel 结果工作簿。

## 功能

- 识别并整理不同来源的关键词与原始指标，避免混淆搜索量、ABA 排名、点击占比、商品数和供需比。
- 先判断产品相关性，再参考流量证据与竞争信号；不以宽泛大词挤掉高相关词。
- 输出分类词表和默认 25 词综合总榜；总榜不足 25 个合格词时如实说明。
- 默认在对话中提供结论，并将 `.xlsx` 工作簿保存到桌面。
- 综合总榜不显示来源文件列；分类和复核工作表保留来源文件以便追溯。

## 使用

将 SellerSprite 或其他关键词研究文件提供给 Codex，并调用 `amazon-keyword-filter` skill。建议提供竞品反查词、搜索结果竞品统一流量词和广泛流量词；亚马逊下拉词或相关搜索词可作为补充意图信号。产品资料默认可省略，skill 会依据竞品反查词确定主题；如产品不同，请随文件说明。

## 文件

- `amazon-keyword-filter/SKILL.md`：完整筛选规则、字段口径、排序逻辑及 Excel 交付规范。
